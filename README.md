# SudokuSolver
A Sudoku Solver made for Android built with Kotlin and Jetpack Compose.

# Requirements for installation
- Your device requires Android API 21 (Android 5.0 or later).
- Enable installing from unknown sources.

# Usage
1. Selecting any cell in the grid allows you to enter any number on it.
2. If you imported the wrong number, reselect the cell to edit it. Or if you inputed a number to the wrong cell, you can clear it by selecting "Clear cell".
3. After you have entered all the numbers on the grid, press "Solve" and the puzzle is solved immediately. Cells with imported numbers have blue numbers, while cells that the solver filled have grey numbers.
4. By pressing "Clear", all cells are emptied.
