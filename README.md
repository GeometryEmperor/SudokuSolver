# SudokuSolver
A Sudoku Solver made for Android.

# Requirements for installation
Your device requires Android API 21 (Android 5.0 or later).

Enable installing from unknown sources.

# Usage
Selecting any cell in the grid allows you to import any number on it.

If you imported the wrong number, reselect the cell to edit it.

Or if you imported a number to the wrong cell, you can clear it by selecting "Clear cell".

After you have imported all the numbers on the grid, press "Solve" and the puzzle is solved immediately. Cells with imported numbers have blue numbers, while cells that the solver filled have black numbers.

By pressing "Clear", all cells are emptied.
